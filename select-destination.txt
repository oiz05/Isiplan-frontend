Implement a “select destination on map and calculate transport options” feature.

Context:
My web app uses React + TypeScript, OpenStreetMap tiles, and Geoapify. The user can already use their current location as origin. Now I need the user to click on the map to choose a destination, mark it on the map, and calculate approximate travel options from the origin to that destination.

Requirements:

1. Destination selection:
- Allow the user to click on the map.
- When the user clicks, capture the clicked coordinates:
  {
    lat: number;
    lng: number;
    label: "Destino seleccionado";
  }
- Save this as destination state.
- Show a destination marker on the map.
- If the user clicks another point, update the destination marker.

2. Origin validation:
- Before calculating routes, check that origin exists.
- If origin is missing, show a message:
  “Primero selecciona tu ubicación de origen.”

3. Route calculation:
- Use Geoapify Routing API:
  https://api.geoapify.com/v1/routing

- Calculate routes for these modes:
  - walk
  - bicycle
  - drive
  - transit

- Use this parameter format:
  waypoints=originLat,originLng|destinationLat,destinationLng
  mode=MODE
  format=geojson
  apiKey=GEOAPIFY_API_KEY

4. Display transport options:
For each available mode, show a card with:
- Transport mode name:
  - A pie
  - Bicicleta
  - Auto
  - Transporte público
- Approximate duration
- Approximate distance
- Optional: short description

5. Route drawing:
- Draw the selected route on the map using the geometry returned by Geoapify.
- When the user selects a different transport mode, update the route line.
- Do not draw all routes at the same time unless the current UI already supports it.

6. Error handling:
- If Geoapify returns no route for a mode, do not crash.
- Show that the mode is unavailable.
- If the API request fails, show:
  “No pudimos calcular la ruta. Inténtalo nuevamente.”

7. Loading states:
- Show loading while routes are being calculated.
- Disable the calculate button while loading.

8. Code quality:
- Use TypeScript types.
- Create a reusable service:
  geoapifyRoutingService.ts
- Create a reusable hook:
  useRouteOptions.ts
- Do not expose the API key directly if the project already has an environment variable system.
- Use:
  import.meta.env.VITE_GEOAPIFY_API_KEY

Acceptance criteria:
- The user can click the map and set a destination marker.
- The app calculates approximate travel time and distance from origin to destination.
- The app displays transport options.
- The selected route is drawn on the map.
- The UI handles loading, errors and unavailable transport modes.
- The code compiles without TypeScript errors.
